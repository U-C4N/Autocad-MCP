# Architecture decision records

One file per decision, numbered in the order they were taken
(`NNNN-short-name.md`). Each record carries a status, the context, the decision
and its consequences. A record is not rewritten once accepted: a later outcome
is appended under its own dated heading, and a reversed decision is superseded
by a new record that names the old one.
