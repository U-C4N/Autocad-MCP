# Track F — architectural 2D (the plan model): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plan model (a wall network with hosted doors and windows) and one
engine that draws it with clean junctions, cut openings and material poché,
computes rooms as the faces the walls enclose, reads rooms from foreign plans,
and delivers schedules, a furniture/sanitary catalogue, a grid, symbols and
dimension chains — 12 tools on both engines.

**Architecture:** Pure modules under `engineering/arch/` emit the typed
primitives of `engineering/mech/primitives.py` with architectural roles; the
async layer draws them through `engineering.mech.draw.draw_prims` (generalised
in Task 1 to take a role → layer map), composing only generic contract members
— no new contract member, so both engines work by construction.

**Tech Stack:** Python 3.11, FastMCP 3, ezdxf 1.4.x, pywin32 (COM), pytest +
pytest-asyncio, ruff — everything through `uv run --frozen`.

**Spec:** `docs/superpowers/specs/2026-09-23-v1.6-arch-design.md` — read it
before your task.

## Global Constraints

- **Run everything through `uv run --frozen …`**, never `uv sync`. If it fails
  with `os error 32` on `.venv/Scripts/autocad-mcp.exe`, use
  `uv run --frozen --no-sync …` for the rest of the task and say so.
- **Commit** with
  `git -c user.name="Umut CAN" -c user.email="umutcan.edizaslan@gmail.com" commit`,
  message ending with these two lines verbatim:
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01FKFStjEFzpGyLq5bMpWxTd`.
- **Known red:** `tests/test_release_consistency.py::test_document_numbers_match_the_tree`
  drifts on the README collected-tests figure whenever tests are added — deselect
  exactly that test in a worktree and say so. Task 9 retakes the figure on main.
- **Units are millimetres, coordinates are WCS**, angles in degrees CCW from +X.
  A wall's `justification` is the side of its axis the wall lies on, *looking
  along the axis from its first point*: `left`, `right` or `center`.
- **Validate before writing**: every refusal fires before the first entity,
  names its path (`walls[2].thickness`), and leaves the drawing untouched.
- **Areas are measured, never typed.** A room's area comes from the planar face
  its label point lies in; no tool accepts an area from its caller.
- **Language**: `lang` is `"en"` (default) or `"tr"`; `"tr"` also switches the
  decimal separator to a comma. Unknown values are refused with the list.
- **Text heights follow the plot scale**: `scale` is a denominator (50 → 1:50);
  a paper height `h` mm is drawn at `h * scale` drawing units. No annotative
  objects (recorded out of 1.6 in track E).
- **Layers** come from `engineering/arch/layers.py::ARCH_ROLE_LAYER`; no tool
  hardcodes a layer name.
- **No standards value is invented.** Catalogue sizes are *nominal catalogue
  dimensions*, stated as such in the data and the tool docstring. The Blondel
  range 600–650 mm is a design rule the stair tool reports, not a code.
- **Before committing:** `uv run --frozen ruff check <changed files>` and
  `uv run --frozen ruff format <changed files>`.
- **Registration gates** (when you register a tool): regenerate
  `docs/tool-inventory.json` (`uv run --frozen python scripts/generate_tool_inventory.py`),
  bump the README release-snapshot tool count, bump the frozen group-size
  snapshot in `tests/test_tool_registry.py`, add an alias record per tool in
  `discovery/aliases.py`.
- **Deviations are data.** If a plan test asserts something the real API
  cannot satisfy, verify the truth by running code, fix the test to that truth
  while keeping the spec's behaviour, and record it. Never weaken a test.
