# v1.7.0 W3 — recipes, skill content, evidence, release: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Versioned task recipes the server serves and tests; the premium skill
rewritten around the 1.7.0 verification workflow; benchmark matrix v8 and a real
A/B gate; a live COM harness that asserts; the skill's A/B evaluation suite; the
release gate and documents for 1.7.0.

**Architecture:** No drafting stage: each task below is implemented TDD-first
from its brief and the spec section it names. The W1 and W2 code on
`release/1.7.0` is the base; read it before starting.

**Tech Stack:** as W1, plus the Claude Code CLI 2.1.310 (`claude plugin validate`,
`claude plugin eval`). **Spec:** `docs/superpowers/specs/2026-10-24-v1.7.0-design.md`
§6, §7, §8.

## Global Constraints

The W1 plan's Global Constraints apply unchanged. In addition:

- **`claude plugin eval` runs cost money:** Task 22 runs exactly one case once
  (`--case <one> --runs 1 --max-cost-usd 2 --no-publish`); the full suite is not
  run inside the workflow.
- **`--no-publish` on every `claude plugin eval` call** — the CLI publishes its
  HTML report to claude.ai by default.
- **Task 23 is the only task that changes the version** (to 1.7.0) and runs
  `uv lock` (then `uv run --frozen --all-extras` once). No push, no tag.
- **The live harness (Task 21)** drives `ComBackend` against AutoCAD 2026; it is
  the only W3 group that touches the live seat.
