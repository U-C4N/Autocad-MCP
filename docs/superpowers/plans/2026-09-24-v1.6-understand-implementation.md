# Track H — understanding foreign drawings, takeoffs, diff, topology: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read drawings somebody else made — a one-call report, a scale check
between a P&ID and its layout, pipe and cable takeoffs whose topology comes
from the P&ID and whose lengths come from the layout, a revision diff and
topology checks — as six tools on both engines.

**Architecture:** One bulk read per drawing into frozen `EntityRecord`s (ezdxf
directly; a live document through a `Document.Export` DXF snapshot that does
not rename it); pure analysis modules under `engineering/understand/`; a thin
async layer and the server tools. No new contract member.

**Tech Stack:** Python 3.11, FastMCP 3, ezdxf 1.4.x, pywin32 (COM), openpyxl
(new `office` extra), pytest + pytest-asyncio, ruff — all through
`uv run --frozen`.

**Spec:** `docs/superpowers/specs/2026-09-24-v1.6-understand-design.md`

  `uv run --frozen --no-sync …` for the rest of the task and say so. A fresh
  worktree venv lacks extras: run commands there as `uv run --frozen --all-extras …`.
- **Commit** with
  `git -c user.name="Umut CAN" -c user.email="umutcan.edizaslan@gmail.com" commit`,
  message ending with these two lines verbatim:
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01FKFStjEFzpGyLq5bMpWxTd`.

  drifts on the README collected-tests figure — deselect exactly that test in a

- **Confidentiality (spec §14):** no client drawing, spreadsheet, file name,
  client or site name, or takeoff quantity from the user's archive enters the
  repository, a test, a fixture, a benchmark result or a commit message. Every
  fixture is synthetic and built by `tests/fixtures/plant_pair.py` (Task 2).
- **Read-only by default:** every tool of this track leaves the drawing
  untouched, except `drawing_diff(markup=True)`; the takeoffs write a workbook
  file, never the drawing.
- **Nothing is invented:** a power value missing from the P&ID stays empty; a
  diameter that cannot be read stays `unassigned`; a length from an unscaled
  P&ID is never presented as a physical length; no cable-section table is
  authored (sections only from a caller's `section_rules`).
- **Units:** analysis runs in drawing units; takeoff lengths are reported in
  metres from the **inferred** unit (spec §5), and a disagreement with
  `INSUNITS` is a warning in the result and on the method sheet.
- **Before committing:** `uv run --frozen ruff check <changed files>` and
  `uv run --frozen ruff format <changed files>`.
- **Registration gates** (when you register a tool): regenerate
  `docs/tool-inventory.json`, bump the README release-snapshot tool count and
  `tests/test_tool_registry.py`'s frozen group sizes, add an alias record per
  tool in `discovery/aliases.py`.
- **Deviations are data**: fix a plan test to the verified truth, keep the
  spec's behaviour, record it; never weaken a test.

## Review Focus

The five real-world inputs the spec implies and no happy-path test exercises —
each seen in, or one keystroke away from, the field drawings of 2026-09-24.
Each line's test lives in the owning task.

1. **AutoCAD text codes in labels** — `%%c51` (AutoCAD's Ø), `\U+2205`,
   `⌀51`, `ø51` and MTEXT format runs (`{\fArial|b0;Ø51}`, `\P`) must all parse
   as the diameter `Ø51`. *Owner: Task 1 (`labels.parse_diameter`).*
2. **Cyrillic look-alike letters in tags** — a Russian-labelled P&ID types
   `Т4100` or `М82` with Cyrillic Т/М; it must match the layout's Latin
   `T4100` / `M82`. *Owner: Task 1 (`labels.parse_tag`).*
3. **The same tag more than once** (two plan copies, a legend, a second sheet)
   — the scale check and the takeoffs must not pick one arbitrarily: they use
   only tags that are unique within the chosen cluster and report the rest as
   `ambiguous`. *Owner: Task 4 (`scale.match_tags`), reused by Task 6.*
4. **Double-drawn pipe** — two overlapping collinear segments on a pipe layer
   (a line drawn twice, or a line over a polyline) must count once, or every
   takeoff doubles silently. *Owner: Task 5 (`network.build_network`).*
5. **A layout whose `INSUNITS` lies** — inches declared over millimetre
   geometry: the takeoff must measure in the inferred unit (no ×25.4) and say
   so. *Owner: Task 6 (`takeoff.pipe_rows`).*

    type: str                       # DXF type: LINE, LWPOLYLINE, POLYLINE, ARC, CIRCLE, SPLINE, ELLIPSE,
                                    # TEXT, MTEXT, INSERT, DIMENSION, LEADER, MULTILEADER, HATCH, …
    layer: str
    space: str                      # "Model" or the paper layout's name
    points: tuple[Pt, ...] = ()     # LINE ends; polyline vertices; TEXT/MTEXT/INSERT insertion; leader vertices
    bulges: tuple[float, ...] = ()  # per vertex, LWPOLYLINE/POLYLINE
    closed: bool = False
    radius: float | None = None     # CIRCLE / ARC
    angles: tuple[float, float] | None = None   # ARC start/end, degrees CCW
    text: str | None = None         # plain text: TEXT, MTEXT (format codes stripped), MULTILEADER, DIMENSION override
    height: float | None = None     # text height
    block: str | None = None        # INSERT block name
    attribs: tuple[tuple[str, str], ...] = ()   # INSERT attributes (tag, value)
    bbox: tuple[float, float, float, float] | None = None   # WCS box (minx, miny, maxx, maxy)
