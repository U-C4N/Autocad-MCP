# Tracks B + G — mechanical 2D part drawer and sheet standard: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One part model and one view engine that draw any revolved or prismatic
machine part — with hidden lines, sections, standard features and ISO
dimensions — plus the standard-parts catalogue, the ISO annotation symbols and
the sheet standard (frames, title blocks, revisions, parts list, balloons,
xrefs, DWG), as 25 tools on both engines.

**Architecture:** Pure geometry modules (`engineering/mech/*`,
`engineering/sheet/*`) emit typed primitive *descriptions*; one async layer
(`draw.py` and the server tools) turns them into backend calls, exactly the way
`gear_draw_*` and `titleblock_apply_iso_a3` already work. Only four operations
differ per engine and become contract members (`xref_attach`, `xref_manage`,
`image_attach`, `drawing_export_dwg`).

**Tech Stack:** Python 3.11, FastMCP 3, ezdxf 1.4.x, pywin32 (COM), pytest +
pytest-asyncio, ruff. Everything runs through `uv run --frozen`.

**Spec:** `docs/superpowers/specs/2026-09-22-v1.6-mech-design.md` — read it
before your task; this plan argues from it and does not repeat its reasoning.

  say so in `deviations`.

  and end every message with these two lines verbatim:
  `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01FKFStjEFzpGyLq5bMpWxTd`.
- **Known red that is not yours:**
  `tests/test_release_consistency.py::test_document_numbers_match_the_tree`
  drifts on the README "collected tests" figure whenever tests are added.
  Deselect exactly that test in a worktree and say so; every other test in that
  file must pass. Task 15 retakes the figure on main.
- **The table rule (spec §5).** Every row of every table under
  `engineering/mech/standards/` is transcribed from the named standard's own
  table, carries a `SOURCE` docstring naming standard + edition + table number,
  and is pinned by a provenance test asserting named values. A size outside the
  transcribed range is refused by name — never interpolated. **If you cannot
  verify a row, do not ship the row**: narrow the coverage, say so in the
  docstring and in `deviations`.
- **Validate before writing** (CLAUDE.md): every refusal fires before the first
  entity reaches the drawing, names the offending path (`segments[2].d_outer`),
  and leaves the drawing untouched.
- **WCS only.** Every coordinate in or out of a tool is WCS. Part-local
  coordinates exist inside the pure modules; `draw.py` is the only place that
  maps them, through the part's placement (`at`, `rotation`).
- **No silent wrong number.** A feature that cannot be projected into a view is
  reported in `omitted: [{"feature": …, "reason": …}]`, never dropped.
- **Layers** come from the role map in `engineering/mech/primitives.py`
  (`visible→GEOMETRY`, `hidden→HIDDEN`, `center→CENTER`, `phantom→PHANTOM`,
  `hatch→HATCH`, `dim→DIM`, `text→TEXT`); no tool hardcodes a layer name.
- **Before committing:** `uv run --frozen ruff check <changed files>` and
  `uv run --frozen ruff format <changed files>`.
- **Registration gates** (only when you register a tool): regenerate
  `docs/tool-inventory.json` with
  `uv run --frozen python scripts/generate_tool_inventory.py`, bump the README
  release-snapshot tool count, bump the frozen group-size snapshot in
  `tests/test_tool_registry.py`, add an alias record per tool in
  `discovery/aliases.py` (`tests/test_discovery_aliases.py` fails otherwise).
- **Deviations are data.** If a plan test asserts something the real API cannot
  satisfy, verify the truth by running code, fix the *test* to that truth while
  keeping the behaviour the spec demands, and record it with the evidence.
  Never delete, skip or weaken a test to get green.

# engineering/mech/primitives.py
Role = Literal["visible", "hidden", "center", "phantom", "hatch", "dim", "text"]
ROLE_LAYER: dict[Role, str]        # visible→GEOMETRY, hidden→HIDDEN, center→CENTER,
                                   # phantom→PHANTOM, hatch→HATCH, dim→DIM, text→TEXT
Pt = tuple[float, float]

class Line(NamedTuple):    p1: Pt; p2: Pt; role: Role = "visible"
class Arc(NamedTuple):     center: Pt; radius: float; start_deg: float; end_deg: float; role: Role = "visible"
class Circle(NamedTuple):  center: Pt; radius: float; role: Role = "visible"
class Poly(NamedTuple):    points: tuple[Pt, ...]; closed: bool = False; role: Role = "visible"
class HatchArea(NamedTuple):
    loops: tuple[tuple[Pt, ...], ...]          # [0] outer, [1:] islands
    material: str = "steel"
class Text(NamedTuple):    at: Pt; text: str; height: float = 3.5; rotation: float = 0.0; role: Role = "text"
class DimIntent(NamedTuple):
    kind: Literal["linear", "aligned", "diameter", "radius", "angular"]
    p1: Pt; p2: Pt
    text_at: Pt | None = None
    text_override: str | None = None
    fit: str | None = None                      # e.g. "H7" → resolved by engineering/fits.py
    tol: dict | None = None                     # {"mode": …, "upper": …, "lower": …} → engineering/tolerances.py
    feature: str = ""                           # the feature id this dimension belongs to
Prim = Line | Arc | Circle | Poly | HatchArea | Text

def bbox(prims: Iterable[Prim]) -> tuple[float, float, float, float]   # (minx, miny, maxx, maxy)
def translate(prims: Iterable[Prim], dx: float, dy: float) -> tuple[Prim, ...]
def rotate(prims: Iterable[Prim], deg: float, about: Pt = (0.0, 0.0)) -> tuple[Prim, ...]
def scale(prims: Iterable[Prim], factor: float, about: Pt = (0.0, 0.0)) -> tuple[Prim, ...]

# engineering/mech/xdata.py
APP_ID = "ACADMCP_MECH"
PAYLOAD_VERSION = 1
def encode(payload: dict) -> list[tuple[int, str]]      # 1001 app id + 1000 chunks ≤ 255 chars
def decode(rows: Sequence[tuple[int, str]]) -> dict     # raises ValueError on a foreign/corrupt payload
# Payload shapes (pinned; both the writer and every reader test them literally):
#   {"v": 1, "kind": "part",      "id": "<hex>", "view": "front", "part": {...part_to_dict...}}
#   {"v": 1, "kind": "std_part",  "designation": "ISO 4014 - M12x60", "standard": "ISO 4014",
#    "size": "M12x60", "qty": 1, "material": "8.8"}
#   {"v": 1, "kind": "balloon",   "item": 3, "targets": ["1A2B", …]}

# engineering/mech/standards/__init__.py

def register(standard: str, rows: dict, coverage: Coverage, source: str) -> None
def lookup(standard: str, size, **kw) -> dict          # ValueError naming standard + coverage when outside
def standards() -> tuple[str, ...]

def hatch_for(material: str) -> dict                   # {"pattern": "ANSI31", "angle": 45.0, "scale": 1.0}
MATERIALS: tuple[str, ...]                             # ValueError lists these when the name is unknown

class Segment(NamedTuple):
    length: float; d_outer: float; d_inner: float = 0.0; taper_to: float | None = None

    name: str; segments: tuple[Segment, ...]; features: tuple[Feature, ...] = ()
