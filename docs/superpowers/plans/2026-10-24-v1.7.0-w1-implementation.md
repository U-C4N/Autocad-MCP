# v1.7.0 W1 — reliability and the independent kit: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cancelled call never shares the document with its still-running worker;
every QA check reads every entity of every space and reports a failure instead of
a clean result; no exported text becomes a spreadsheet formula; spec inputs are
validated in one place; the premium skill is back as a Claude Code plugin;
search-mode clients can read one tool's full schema; the standards coverage is
published.

**Architecture:** Lifecycle fixes inside `_async` / `_run` and the quarantine
module; one shared all-spaces snapshot per QA run; two small pure modules
(`engineering/export/cells.py`, `engineering/validation.py`); a plugin directory
generated from the canonical skill; one synthetic discovery tool. No new contract
member.

**Tech Stack:** Python 3.11, FastMCP 3.4.5, ezdxf 1.4.4, pywin32 (COM), openpyxl,
anyio, pytest + pytest-asyncio, ruff — all through `uv run --frozen`.

**Spec:** `docs/superpowers/specs/2026-10-24-v1.7.0-design.md` (§3 execution
model, §4 W1, §8 refusals / Review Focus / gates).

  Never `uv sync`, never `uv lock` in W1.
- **pytest needs a basetemp:** always pass `--basetemp=out/pytest/<group-or-task>`
  (`out/` is git-ignored). The default `%TEMP%\pytest-of-VECTOR` is not writable on
  this machine (WinError 5 at fixture setup).
- **Commit** with
  `git -c user.name="Umut CAN" -c user.email="umutcan.edizaslan@gmail.com" commit`,
  message ending with the line
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Known red inside a task:** `tests/test_release_consistency.py::test_document_numbers_match_the_tree`
  drifts on README's collected-tests figure when a task adds tests — deselect

- **Before committing:** `uv run --frozen ruff check <changed files>` and
  `uv run --frozen ruff format <changed files>`.
- **Registration gates** (a task that adds or changes a tool, resource or prompt):
  regenerate `docs/tool-inventory.json` (`scripts/generate_tool_inventory.py`),
  move `tests/test_tool_registry.py`'s frozen sizes and the README release-snapshot
  counts, add alias records in `discovery/aliases.py`, keep SECTION banner counts
  equal to the decorators beneath them.
- **Live AutoCAD 2026** is running. Attach with
  `win32com.client.GetActiveObject("AutoCAD.Application")` only — never `Dispatch`,
  never launch one. A probe holds its own `Document` from `Documents.Add()`, never
  goes through `ActiveDocument`, and closes it with `Close(False)` in a `finally:`.
  `RPC_E_CALL_REJECTED` (-2147418111) is contention: retry with backoff up to
  ~90 s. Do not drive `ComBackend` against the live seat inside a parallel group.
- **COM pitfalls** (measured in 1.6; write against them): GetVariable/SetVariable
  live on the document; sysvar angles are radians; GetEntity's point is UCS;
  makepy narrows Dictionaries/Item/AddObject results — un-narrow with
  `win32com.client.dynamic.Dispatch(obj._oleobj_)`; PlotToFile needs
  BACKGROUNDPLOT=0; `_UNDO B` without a mark hangs; `SaveAs` re-points the open
  document; `ActiveDocument` can change under the server between calls;
  `Document.Export(path, "DXF", ss)` wants `"DXF"`, not `".dxf"`; a fake that models
  a member the real object lacks enshrines the bug — fakes use measured member
  names.
- **Deviations are data:** if a plan test asserts something the real API cannot
  satisfy, verify the truth by running code, fix the test to that truth while
  keeping the spec's behaviour, and record it. Never delete, skip or weaken a test.
- **Confidentiality:** no client drawing, file, client or site name, tag or
  quantity from the maintainer's archive enters anything. Fixtures are synthetic.
- **Triage assignments:** `docs/analysis/backlog-1.7.0-triage.json` (Task 0) lists
  the backlog rows each task owns; a task fixes its rows with a test each and
  records them in its commit message.

## Review Focus

1. **A cancellation at every point of a call's life** — while queued, while the
   worker runs, as it finishes, after the original deadline; with
   `EZDXF_CALL_TIMEOUT` both on and `0`. A second call must never run while the
   first worker is alive; the lock is released exactly once. *(Task 1)*
2. **The offending entity at 5,001, 10,001 and last, and on a paper layout; a
   check that raises.** *(Task 2)*
3. **Text cells `=1+1`, `@x`, a leading tab, a genuine `-12.5`.** *(Task 3)*

class AbandonedCall:                       # existing; gains:
    def set_on_finish(self, hook: Callable[[], None]) -> bool
        # registers a one-shot hook the WORKER THREAD calls when it ends; returns
        # False when the worker already finished (the caller releases at once).
        # A small threading.Lock closes the race; the hook runs at most once.
class QuarantineRecord:                    # existing; gains:
    cause: str                             # "deadline" | "cancelled_then_deadline"

# backends/ezdxf_backend.py (Task 1)
async def _async(self, func, *args, quarantine_exit: bool = False,
                 readonly: bool = False, **kwargs)
    # readonly=True: an overrun keeps the lease until the worker ends ("busy"
    # to waiters) and never quarantines.
self.call_outcomes: collections.deque     # maxlen 50, rows:
    # {"call": str, "outcome": "cancelled_queued" | "cancelled_running" |
