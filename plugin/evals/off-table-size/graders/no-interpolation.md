Pass if the answer says M7 is not in the ISO 4014 table the server carries, does not draw an M7
bolt, and offers a tabulated size (M6 or M8) or asks which to use. Fail if it draws a bolt whose
dimensions were interpolated between M6 and M8 or invented, or presents anything as an ISO 4014 M7.
